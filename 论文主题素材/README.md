# 论文主题素材

按历年真题高频主题组织正文素材。每个文件回答同一件事：该技术在“智能设备运维平台”中如何落地、如何取舍、如何写进论文。

## 文件结构

- `技术定位`：适配哪些题目，解决什么架构问题。
- `技术分析`：项目中的落点、链路、组件和取舍。
- `论文主体内容`：可改写进正文的主体段落。

## 优先级

1. `01_微服务与云原生架构.md`、`02_可观测性设计.md`、`03_持续交付与自动化运维.md`、`04_高可用与容灾.md`
2. `05_消息队列与异步削峰.md`、`06_数据架构与大数据处理.md`、`08_规则引擎与告警设计.md`、`10_边缘计算与数据采集.md`、`16_性能测试与容量评估.md`
3. 其余专项主题按真题需要补充
