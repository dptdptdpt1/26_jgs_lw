# 论文主题素材

按历年真题高频主题组织正文素材。每个文件回答同一件事：该技术在“智能设备运维平台”中如何落地、如何取舍、如何写进论文。

## 文件结构

- `技术定位`：适配哪些题目，解决什么架构问题。
- `技术分析`：项目中的落点、链路、组件和取舍。
- `论文示例`：按 [论文模版.md](../论文模版.md) 组织的完整示例，包含摘要、正文和结论。

目录已按复习优先级编号，依据 [论文真题汇编.md](../论文真题汇编.md) 中的真题频次、主题覆盖面和本项目适配度排序：

1. `01_微服务与云原生架构.md`
2. `02_数据架构与大数据处理_收敛版.md`
3. `03_数据架构与大数据处理_详细版.md`
4. `04_软件测试与质量保障.md`
5. `05_持续交付与自动化运维.md`
6. `06_高可用与容灾.md`
7. `07_负载均衡与流量分发.md`
8. `08_消息队列与异步削峰.md`
9. `09_边缘计算与数据采集.md`

其中 `02_数据架构与大数据处理_收敛版.md` 是考场主用版本，`03_数据架构与大数据处理_详细版.md` 只作为补充查阅。
