# 技术到场景总览

项目基础参数统一参考 [项目固定背景.md](/Users/duanpeitong/Desktop/work/study/26_jgs_lw/项目固定背景.md)。

## 使用方法

本目录用于按照“技术原理 -> 项目落点 -> 决策原因 -> 论文写法”的顺序复习。

建议每种技术至少掌握以下问题：

1. 这个技术在项目中解决了什么问题
2. 为什么不用别的方案
3. 这个技术具体落在哪 2 到 3 个场景里
4. 这个技术带来了什么收益
5. 这个技术的风险和控制点是什么

## 推荐复习方式

- 先理解技术原理
- 再记住它在本项目中的 2 到 3 个落地场景
- 最后练习如何把技术写进论文段落

## 论文答题提醒

不要孤立地写技术名词，而要写成：

“在某个业务场景下，为了解决什么问题，我为什么选用了该技术，它是如何与其他模块协同的，最终取得了什么效果。”
