# 某汽车零部件集团“智能设备运维平台”

系统架构师考试论文素材库。固定项目场景见 [项目固定背景.md](项目固定背景.md)。

## 入口

- [论文真题汇编.md](论文真题汇编.md)：历年真题、主题频率、素材映射
- [论文模版.md](论文模版.md)：摘要、正文、结论模板
- [项目图示.md](项目图示.md)：项目架构与关键链路图示
- [论文主题素材](论文主题素材)：按真题主题组织的正文素材
- [附录](附录)：跨主题复用的公共口径

## 使用顺序

1. 查 [论文真题汇编.md](论文真题汇编.md)，确定主题和素材组合。
2. 读 [项目固定背景.md](项目固定背景.md)，统一项目参数。
3. 从 [论文主题素材](论文主题素材) 取 2 到 3 段主体素材。
4. 用 [论文模版.md](论文模版.md) 组装并重写。
